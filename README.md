# Quick Trim

ブラウザで動く、無音検出つきの動画トリマーです。`file://` での直接起動や手動での
`localhost` 起動なしで使えるよう、ダブルクリックで起動できるランチャーを同梱しています。

## 特長

- **無音検出 + レビューUI**: 検出した無音区間を「無音候補 1/18」のように1件ずつ確認。
  前へ / 次へ / 再生 / 採用して削除 / スキップ を操作できます。候補を選ぶと再生ヘッドが
  区間の少し前へ移動し、タイムライン上で該当区間が強調表示されます。
  **自動削除はせず、採用した候補だけが削除対象**になります。
- **カット・分割**: 再生ヘッドで分割し、区間を選んで削除/復元。
- **書き出し**: 削除区間を除いた部分をつなげて動画(webm)として書き出し。編集内容を
  EDL(JSON)としても書き出せます。

## 起動方法（macOS）

1. `start_quicktrim.command` をダブルクリックします。
2. ローカルサーバー（`python3 -m http.server 8765`）が起動し、
   既定のブラウザで `http://localhost:8765/quicktrim.html` が開きます。
3. ウィンドウを閉じる（または Ctrl-C）とサーバーが停止します。

> 初回はmacOSのセキュリティにより実行確認が出る場合があります。`.command` を右クリック →
> 「開く」を選ぶか、`chmod +x start_quicktrim.command` を実行してください。

## 起動方法（その他のOS / 手動）

```bash
python3 -m http.server 8765
# ブラウザで http://localhost:8765/quicktrim.html を開く
```

## 使い方

1. 右上の「動画を開く」で動画ファイルを選択します。
2. 「無音検出」を押すと無音候補が一覧・レビューUIに表示されます（しきい値dB・最短無音・前余白を調整可）。
3. レビューUIで候補を確認し、不要な無音は「採用して削除」、残したいものは「スキップ」。
4. 必要に応じてタイムラインで手動分割・区間削除も可能です。
5. 「動画を書き出し(webm)」で削除区間を除いた動画を出力します。

### キーボードショートカット（レビュー中）

- `←` / `→`: 前 / 次の候補
- `Space`: 候補を再生
- `Enter`: 採用して削除
- `X`: スキップ
